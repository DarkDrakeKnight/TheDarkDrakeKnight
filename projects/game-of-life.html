Summary

Game of Life is a simulation project focused on logic, state changes, and visual feedback. The project demonstrates how simple rules can create more complex behavior over time. It is a useful example of my ability to work through a systems-based challenge and produce a working application.

This project is also a good example of my interest in programming systems that are easy to explain but still engaging to watch.

Project Breakdown

  • Project Type: Simulation / Logic / Programming
  • My Role: Implementation, testing, and presentation
  • Tools Used: C#, programming logic, build packaging
  • Focus Areas: Rules, update loops, and state changes
