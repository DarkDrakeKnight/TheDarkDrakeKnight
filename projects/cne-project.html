Summary

CNE Project is the executable used to get the Spaghetti Relay server running. This project was built to support communication between instances and to demonstrate how the relay process works. The focus of the project is reliability, setup, and making the workflow understandable for the user.

This is a more technical project in my portfolio and shows my interest in systems that support gameplay and connectivity. Even though it is not a traditional game, it reflects the kind of problem-solving that is useful in game development.

Project Breakdown

  • Project Type: Networking / Utility / Systems
  • My Role: Build support, setup, testing, and presentation
  • Tools Used: C#, Windows executables, relay workflow testing
  • Purpose: Start the relay server used by the GUI and communication demo
