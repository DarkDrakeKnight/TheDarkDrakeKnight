Summary

Behind the Line is a gameplay project built around a Tetris-style system used inside a larger game concept. The project was designed to show how puzzle logic, timing, and player interaction can work together in a compact experience. It is one of the clearest examples of my interest in structured gameplay systems.

This project also helped me think more carefully about how a small mechanic can support a larger game idea. I focused on making the system readable, functional, and fun to watch in motion.

Project Breakdown

  • Project Type: Gameplay / Puzzle / Systems
  • My Role: Design, implementation, testing, and demo presentation
  • Tools Used: Unity, C#, Git/GitHub
  • Focus Areas: Timing, rules, game flow, and visual feedback

Reflection

This project strengthened my understanding of how rules and timing affect player experience. It also helped me practice thinking about gameplay in small, testable pieces instead of trying to build everything at once. That approach has helped me become more organized when developing systems.
