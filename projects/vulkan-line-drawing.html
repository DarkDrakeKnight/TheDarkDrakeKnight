Summary

Vulkan Line Drawing is a graphics programming project that focuses on rendering lines and displaying performance data. The final build shows the completed output, and I used a separate folder containing the files needed to run the project. This project highlights my interest in low-level graphics and technical problem-solving.

It is one of the strongest examples in my portfolio of working through complex systems and getting a result that can be shown clearly.
