Summary

Spaghetti Relay is a GUI project that opens the relay and allows communication between two running instances. It is supported by the CNEProject executable, which starts the server side of the workflow. The video demonstrates the full process and shows how the relay behaves when connected.

This project helped me practice presenting a technical process in a way that is easier to understand and repeat. It also reflects my interest in systems, tools, and communication-based functionality.

Project Breakdown

  • Project Type: GUI / Networking / Utility
  • My Role: Setup, testing, workflow demonstration, and presentation
  • Tools Used: C#, GUI tools, Windows executables
  • Purpose: Open the relay and connect two instances for communication
